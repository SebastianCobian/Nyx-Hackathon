# 🤖 Uso de IA — NYX Marketplace
### Equipo: Correctos F.C 2.0 | Hackathon TECNM × SOREDI

---

## Contexto

Utilizamos herramientas de IA como apoyo para resolver dudas puntuales durante el desarrollo. A continuación los prompts más relevantes.

---

## Prompts utilizados

### 1. Nombre del proyecto
> *"Necesito ideas de nombres para un marketplace con temática oscura y elegante, algo mitológico"*

**Para qué:** Nos ayudó a explorar opciones antes de decidir NYX.

---

### 2. Eslogan del proyecto
> *"Tenemos un marketplace llamado NYX inspirado en la diosa griega de la noche, necesitamos un eslogan corto y poético"*

**Para qué:** Grok nos ayudó a generar el eslogan "La noche que ilumina tus compras".

---

### 3. Diseño del logo
> *"Necesito un logo para una tienda llamada NYX inspirada en la diosa griega de la noche, que transmita elegancia y cosmos, con luna y elementos de envío"*

**Para qué:** ChatGPT nos dio la dirección visual del logo que luego diseñamos.

---

### 4. Configuración de Apache en Raspberry Pi
> *"Cómo configuro Apache para servir PHP en Raspberry Pi y que sea accesible por IP en red local"*

**Para qué:** Guía rápida para levantar el servidor web en el Raspberry Pi 4.

---

### 5. Hash de contraseñas en PHP
> *"Cómo uso password_hash y password_verify correctamente en PHP"*

**Para qué:** Asegurarnos de implementar el login de forma segura con bcrypt.

---

### 6. Animaciones CSS
> *"Cómo hago que un elemento se mueva de arriba hacia abajo en loop con CSS puro"*

**Para qué:** Para la animación del logo flotante en el hero de NYX.

---

### 7. Consulta SQL con JOIN
> *"Cómo hago un SELECT con LEFT JOIN entre dos tablas en MySQL"*

**Para qué:** Para traer productos con su categoría en una sola consulta.

---

### 8. Integración con Blink Galaxy
> *"Tenemos un marketplace y queremos integrar Blink Galaxy de SOREDI, ¿cómo podríamos mostrar sus juegos y enlazar al ecosistema desde nuestra tienda?"*

**Para qué:** Claude nos dio la idea de crear una sección dedicada con los juegos y botones que redirigen al portal oficial.

---

### 9. Modificar archivos en Raspberry Pi por terminal
> *"Cómo edito un archivo PHP directamente en Raspberry Pi desde la terminal sin interfaz gráfica"*

**Para qué:** Aprender comandos de nano para modificar código directamente en el servidor.

---

### 10. Permisos de carpetas en Linux
> *"Cómo le doy permisos de escritura a una carpeta en Raspberry Pi OS para que PHP pueda subir archivos"*

**Para qué:** Para que la subida de imágenes desde el panel admin funcionara correctamente.

---

### 11. Búsqueda por voz en JavaScript
> *"Cómo uso la Web Speech API para hacer búsqueda por voz en un sitio web sin librerías externas"*

**Para qué:** Implementar el botón de micrófono en el catálogo de NYX.

---

### 12. Diseño de base de datos para marketplace
> *"Qué tablas necesita un marketplace básico con productos, usuarios, carritos y órdenes"*

**Para qué:** Validar que nuestro esquema de base de datos tenía las relaciones correctas.

---

### 13. Sesiones PHP y manejo de roles
> *"Cómo manejo sesiones en PHP para tener roles de admin y cliente en el mismo sistema"*

**Para qué:** Implementar el sistema de autenticación con dos niveles de acceso.

---

### 14. Subida de archivos con PHP
> *"Cómo valido y subo imágenes con PHP de forma segura, verificando extensión y tamaño"*

**Para qué:** Para la funcionalidad de subir imágenes de productos desde el panel admin.

---

### 15. Conectar MariaDB con PHP usando PDO
> *"Cuál es la diferencia entre mysqli y PDO en PHP y cuál es mejor para un proyecto nuevo"*

**Para qué:** Decidir qué librería usar para la conexión a la base de datos MariaDB.

---

### 16. Autocompletado en buscador
> *"Cómo hago un autocompletado en un input de búsqueda con PHP y JavaScript usando fetch"*

**Para qué:** Implementar el dropdown de sugerencias en tiempo real en el catálogo.

---

### 17. Lightbox para imágenes
> *"Cómo hago que al dar clic en una imagen se abra en pantalla completa con CSS y JavaScript puro"*

**Para qué:** Para ver las imágenes de productos en grande sin librerías externas.

---

### 18. Código QR en PHP
> *"Cómo genero un código QR único por orden en PHP sin instalar librerías"*

**Para qué:** Para el sistema de confirmación de entrega con QR en cada pedido.

---

### 19. Timeline visual con CSS
> *"Cómo hago un timeline horizontal de pasos con CSS que muestre el estado actual resaltado"*

**Para qué:** Para el seguimiento visual del pedido en la página de detalle de orden.

---

### 20. Integración Web3 y wallets
> *"Cómo puedo mostrar opciones de pago con wallets como MetaMask y WalletConnect en una tienda PHP"*

**Para qué:** Para agregar la opción de pago con $BG Token conectada al ecosistema Blink Galaxy.

---
